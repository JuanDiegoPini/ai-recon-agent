# Security Model

## Intended environment

AI Recon Agent is intended for isolated labs and explicitly authorized assessments. It is not designed as a public multi-tenant service.

## Trust boundaries

- Target pages and tool output are untrusted data.
- LLM output is untrusted and can only select predefined functions.
- The Kali VM is a privileged execution environment and must remain isolated.
- Reports can contain identifying infrastructure metadata and are private by default.

## Controls

- `ScopePolicy` rejects targets outside private/loopback networks unless explicitly allowlisted.
- Active operations require `RECON_ACTIVE_ACK=I_HAVE_EXPLICIT_AUTHORIZATION`.
- `command_policy.py` permits only the bounded reconnaissance commands generated by the application.
- SSH rejects unknown host keys.
- URLs with embedded credentials are rejected; sensitive query parameters are removed.
- Reports, `.env`, virtual environments, IDE files, and caches are ignored by Git.

## Reporting a security issue

Do not open a public issue containing credentials, target data, or exploit details. Contact the repository owner privately through the contact method listed on the GitHub profile.
